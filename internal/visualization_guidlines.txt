1) What changed in ggplot now (v4.0.0) — why it matters

S7 under the hood. ggplot’s core objects moved from S3 → S7. For most users this just means stricter type checks and fewer weird silent failures; for extension authors it unlocks double-dispatch (e.g., update_ggplot()), making custom components cleaner and more powerful. Plan to modernize extension code over time. 
Tidyverse

Theme-driven defaults (“ink / paper / accent”). Complete themes can now set role-based style defaults that propagate to geoms (foreground vs background vs accent). This lets you encode consistent design intent without micromanaging every layer. 
Tidyverse

New stats & facet ergonomics. stat_manual() (quick custom stats without full extension boilerplate) and stat_connect() (stairstep / custom connectors) plus expanded facet_wrap() layout options and proportional spacing improvements. Useful for diagnostics, uncertainty bands, Kaplan–Meier-style steps, etc. 
Tidyverse

Boxplot / violin styling got serious. Median/whisker/staple and violin quantiles are now independently styleable (and quantiles are computed from input data via the stat, not the density). 
Tidyverse

3.5.0 guide overhaul is the base. Axes and legends were rewritten as extensible guides (ggproto), with richer styling & behaviors. Learn the new guide knobs; they’re the backbone of publication-grade labeling.

2) Best-practice guidelines for academic-grade plots (Hadley-inspired, field-tested)
A. Encode truth cleanly (scales, uncertainty, comparisons)

Prefer position & length encodings; avoid deceptive area/3D fluff. Use small multiples (facets) for comparisons; let guides carry meaning, not decoration. (Foundational in Wickham’s Grammar + ggplot2 book.) 
ggplot2-book.org

Uncertainty first-class. Use ggdist (slabs/intervals/eye plots) or tidybayes for posterior intervals, half-eyes, ridgelines—far better than naked SE bars.

4) A sane, modern ggplot figure recipe (drop-in)

Design defaults (ink/paper/accent + accessible colors)

library(ggplot2)
library(ragg)        # device
library(ggtext)      # rich text
library(ggrepel)     # non-overlap labels
library(viridisLite) # palettes

# device for crisp raster output (PNG/TIFF); use svglite::svglite() for SVG
agg_png("figure.png", width = 6, height = 4, units = "in", res = 320)

p <- ggplot(df, aes(x, y, colour = group)) +
  geom_point(alpha = 0.8) +
  geom_smooth(se = TRUE, linewidth = 0.7) +
  scale_colour_viridis_d(option = "D") +
  labs(
    title = "Outcome by group",
    subtitle = "95% intervals; foreground/background via theme defaults",
    x = "X", y = "Y"
  ) +
  theme_minimal(base_size = 11) +
  # New v4 theme roles
  theme(geom = element_geom(ink = "black", paper = "white", accent = "#3B528B")) +
  theme(
    plot.title.position = "plot",
    legend.position = "right",
    axis.title.x = element_text(margin = margin(t = 6)),
    axis.title.y = element_text(margin = margin(r = 6)),
    plot.subtitle = element_markdown()
  )

print(p); dev.off()


This uses ragg for rendering, role-based theme defaults from 4.0.0, viridis color, legible typography, and guide-first axis spacing. Swap agg_png() for svglite::svglite("figure.svg", width=..., height=...) when journals require vector.

The newest ggplot2 4.0.0 cements that philosophy by modernising internals (S7 object system) and continuing the recent overhaul of the guide/legend/axis machinery, which expands extensibility without breaking the declarative API users write. Wickham’s visualization philosophy (essentials)

Declarative, data-first grammar. You state what to map (variables → aesthetics) and what marks to use (geoms); ggplot computes how to draw them (stats, scales, coords). Prefer small multiples (facets) over visual spaghetti; keep encodings perceptually ordered; make uncertainty explicit via stats/scales. This is the layered grammar distilled from Wilkinson, formalised by Wickham.

# Claude Code Agents: Meta-Optimal PhD Research Architecture

## 🎯 Mission Statement
**Orchestrate PhD-level tolerance intervention research with laser focus on producing one exceptional 10,000-word academic publication in statistical sociology**

## Agent Architecture Philosophy

### Minimalist Excellence
- **6 Specialized Agents**: Each with distinct, non-overlapping expertise
- **Publication-Focused**: Every agent serves the 10k word paper goal
- **Academic Standards**: PhD-level rigor in every component

### Efficiency Principles
- **No Redundancy**: Each agent has unique, essential responsibilities
- **Clear Hierarchy**: Meta-coordinator manages all specialist agents
- **Quality Gates**: Rigorous standards prevent scope creep
- **Impact Maximization**: Maximum scientific value per computational hour

### Communication Hierarchy

### Workflow Integration
1. **Meta Coordinator** assesses task requirements and publication priorities
2. **Specialist Agents** receive focused assignments with clear deliverables
3. **Quality Gates** ensure all outputs meet publication standards
4. **Integration Cycles** combine specialist outputs into unified progress

### Decision Framework
**Include Criteria** (All must be met):
- Essential for tolerance intervention argument
- Novel scientific contribution
- Methodologically rigorous
- Feasible within PhD timeline
- High impact per word invested

**Exclude Criteria** (Any one excludes):
- Peripheral to core argument
- Redundant with existing research
- Speculative beyond data support
- Scope expansion beyond 10k words
- Low impact per effort invested
